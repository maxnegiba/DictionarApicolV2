# Roadmap G0–G8, RO + EN

- **G0 Foundation:** repository, policy, schemas, validator, CI, draft examples; private manuscript import deferred while repository is public.
- **G1 Intake:** classify every extracted V1 candidate with provenance, risk, and outcome; never auto-approve; separate language-specific labels.
- **G2 Coverage:** 12-module scope matrix, crosswalk between shared IDs, RO/EN coverage and geography.
- **G3 Pilot:** 40–60 terms, 2–3 chapters, 5–8 SOPs, 10–15 TAX profiles, health/regulatory examples; both editions reviewed.
- **G4 Production:** evidence dossiers first, then distinct RO and EN publication texts, batched by topic.
- **G5 Cross-audit:** contradiction, cross-reference, terminology, localization, bibliography and licensing audits.
- **G6 Outside review:** qualified apiculture, veterinary and botany reviewers where relevant.
- **G7 Copyedit/typeset:** independently proofread editions; cross references and accessibility; proof PDFs.
- **G8 Publish gate:** zero unresolved critical flags, print proofs approved separately for RO and EN.

Only APPROVED content with resolved edition-specific gates can enter a release.
